# Proyecto Gao

[![Licencia](https://img.shields.io/badge/Licencia-MIT-blue.svg)](https://opensource.org/licenses/MIT)

Proyecto Gao es una plataforma de análisis y visualización de datos de anuncios clasificados en Cuba, integrando fuentes como Revolico y Porlalivre. Permite explorar tendencias, realizar análisis de datos y visualizar información relevante para investigadores, estudiantes y público general interesado en el mercado inmobiliario cubano.

- **Web del proyecto:** [https://huggingface.co/spaces/barbaroyoel/ProyectoGao](https://huggingface.co/spaces/barbaroyoel/ProyectoGao)

---

## 1. Objetivos

- Recolectar, limpiar y procesar datos de anuncios clasificados cubanos.
- Ofrecer herramientas de análisis y visualización de datos.
- Facilitar la investigación sobre tendencias y dinámicas del mercado digital en Cuba.

---

## 2. Estructura del Proyecto

- `Inicio.py`: Script principal para ejecutar la aplicación.
- `src/`: Scripts de análisis, limpieza y procesamiento de datos.
- `data/`: Datos crudos, procesados y externos.
- `notebooks/`: Notebooks para análisis exploratorio y desarrollo.
- `pages/`: Páginas interactivas de la aplicación.
- `assets/`: Recursos gráficos (iconos, logos).

---

## 3. Instalación y Ejecución

Clona el repositorio y configura el entorno de Python:

```bash
git clone https://github.com/tu-usuario/proyecto_gao.git
cd proyecto_gao
pip install -r requirements.txt
```

Ejecuta la aplicación principal:

```bash
streamlit run Inicio.py
```

O accede directamente a la web:
[https://huggingface.co/spaces/barbaroyoel/ProyectoGao](https://huggingface.co/spaces/barbaroyoel/ProyectoGao)

## 7. Resultados y Conclusiones

El proyecto ha permitido centralizar y analizar grandes volúmenes de datos de anuncios clasificados cubanos, facilitando la identificación de tendencias y patrones relevantes. La plataforma web ofrece una experiencia interactiva y accesible para usuarios de distintos niveles técnicos.
